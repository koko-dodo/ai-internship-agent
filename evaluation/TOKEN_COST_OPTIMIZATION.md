# Day 6：一次格式层成本优化

## 诊断与唯一优化点

依据保存的两份真实 `real.json` 和 `reports/LIVE_ANALYSIS.md`：

| 真实历史运行 | Fixed total tokens | Agent total tokens | Agent 行动决策调用 | 决策 total tokens |
| --- | ---: | ---: | ---: | ---: |
| 02 | 2,125 | 4,488 | 2 | 2,350 |
| 05 | 2,083 | 7,266 | 4 | 5,119 |

这些是旧运行的实际 API usage，绝不作为优化后的用量。05 的四次决策占其总 tokens 约 70.5%。

- **重复上下文**：`_decision_data()` 已不含简历全文或已验证项目证据全文。重复内容主要是决策 Schema、行动规则、授权/可搜索列表、技能状态、预算、历史及反馈；不是简单删除长简历就能解决的问题。
- **冗余决策**：两例都有最终 FINISH 调用。若省略调用，需要明确 Python 代决策边界及改变调用/终止语义；本次不做。
- **低收益检索**：05 第二次搜索生产条件返回 0 个候选；这是另一个策略问题，本次不改变检索或目标语义。
- **交互恢复**：05 ASK_USER 与恢复后的 FINISH 各一次调用。用户陈述仍需保留为未经核实的信息，不能为了节省上下文删除它或直接当证据。

选择风险最低的单点：**只对 GatheringDecision 请求的 JSON 使用紧凑分隔符** `(',', ':')`。删除字符串外的序列化空格；所有 Schema、数据字段、字段顺序、字符串内容、指令、权限、预算和历史保持不变。证据重评及初始匹配的提示文本保持逐字节一致。

不调整 prompt 内容、Schema、模型参数、检索策略、结束策略或恢复预算；没有第二项优化或连续调参。技能对齐、Gold、证据验证和确定性评分规则均未改。

## 离线 A/B 方法

`evaluation.token_cost_ab` 用同一控制器的两种编码器比较：

- A：优化前默认 `json.dumps(..., ensure_ascii=False)`。
- B：行动决策紧凑 JSON，其他请求仍为 A。

执行全部 12 个原有 ScriptedLLM 案例，以及 02/05 的已保存 Agent 响应回放。回放顺序、输入文件、授权、预算、回复与工具相同，执行真实本地工具和验证逻辑，不构造 SDK 客户端。固定响应不会对提示变化作出新的语义决策。

逐请求比较：指令、解析后的 Schema/data、工具列表完全相等；非决策提示逐字节相等。逐运行比较：除实际耗时外的完整 Run（含请求数、状态、引用、分数、trace、交互、检索与预算）完全相等。

旧真实报告没有保存 HTTP prompt，以下上下文长度是使用当前代码与冻结材料重建的**离线回放长度**，不是对历史线上 prompt 的直接测量。

## 实际离线数值

长度定义：对所有行动决策消息的 `message.content` 计算 Python `len()` 并求和，包含指令、Schema 和数据；单位是字符，不是字节或 tokens。

| 已保存响应回放 | 决策调用 A → B | 决策上下文字符 A → B | 全部请求 A → B | 检索尝试 A → B | 状态 |
| --- | --- | --- | --- | --- | --- |
| 02 | 2 → 2 | 6,115 → 5,738 | 5 → 5 | 1 → 1 | finished → finished |
| 05 | 4 → 4 | 13,672 → 12,837 | 7 → 7 | 2 → 2 | waiting 后恢复为 finished，两侧相同 |

12 个 Mock 案例均减少决策上下文字符，全部 14 组检查通过。07 保持 waiting_for_user；08 保持询问/回复/完成且没有文件证据升级；10 保持 permission_denied；11 保持 tool_error；12 保持 invalid_target 后有限纠正。05 回放的查询实践、生产限制、partial / not_found 状态与全部引用不变。

## 保留决定与风险

保留该优化：本地验证显示上下文明确缩短，结构、证据、行动轨迹及安全约束不变；改动只在序列化格式层。它不会减少模型调用数或无效检索，预期收益有限。

JSON 语义等价不保证真实 LLM 输出分布完全一致；实际 tokenizer 对空白的处理、实际用量和随机输出仍需真实验证。可以手动进行一次预算受限的小规模验证，先固定当前协议、对比决策与引用，再看 API usage；但此次收益较小，不值得为其扩展实验规模，也不能保证节省费用。本次没有执行或自动安排任何付费调用。
